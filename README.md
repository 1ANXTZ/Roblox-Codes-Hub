# Roblox Codes Hub

A modern website for Roblox game codes with automatic code management, responsive design and a clean user experience.

---

## Features

- Active Roblox codes
- Automatic expired code detection
- Fast search
- Categories
- Favorites
- Copy code with one click
- Responsive design
- Dark / Light theme
- Admin Dashboard
- Local persistence
- SEO optimized
- Open Graph support

---

## Built With

- HTML5
- CSS3
- JavaScript (ES Modules)
